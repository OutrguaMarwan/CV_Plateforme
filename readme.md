# CV Projet

CV Projet est une plateforme d’aide à la recherche d’emploi. Elle centralise les offres, l’analyse de CV, les compétences et le suivi des candidatures dans une interface unique.

## Fonctionnalités

- Création de compte et connexion
- Tableau de bord personnel
- Recherche et filtrage d’offres d’emploi
- Consultation des détails d’une offre
- Espace d’analyse de CV
- Gestion des compétences et du profil
- Suivi des candidatures

## Technologies

- **Frontend :** React, TypeScript, Vite
- **Backend prévu :** Python "Django"
- **Data science :** analyse des CV et rapprochement entre profils et offres
- **DevOps / Cloud :** automatisation et déploiement de la plateforme

> Le dépôt contient actuellement le frontend. Le backend Python, les fonctionnalités de data science et l’infrastructure cloud sont à développer et intégrer par l’équipe.
